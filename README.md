# UniSync

UniSync is a dual-calculator platform for personal metric analysis, providing:

- **SoulCode Calculator** — personal metric analysis with a comprehensive assessment framework
- **LifeCode Calculator** — core life metric computation with rigorous mathematical optimization
- **Educational Framework** — transparent, explainable calculation methodology for users
- **Strategic Vision** — overarching direction and feature roadmap

**Status:** Phase 1 — Specification & Architecture Design
**Owner:** Project Lead (RichVillain)

UniSync originated as a workstream inside the [NDrap platform](https://github.com/RichVillain/Ndrap-platform) monorepo, then was extracted into this standalone repository — it is its own product, not part of the NDrap ecosystem. See `docs/PROVENANCE.md` for the extraction history.
